本次为**功能增强 + 行为调整 + 修复**版本，无破坏性变更，升级无需改动配置。

## 网页读取与搜索

- **抓取结果改为结构化 Markdown**：网页正文中的标题层级、链接地址、代码块、列表、表格与引用此前会被拍平成纯文本，现在都保留下来——读文档时「链接去哪」「代码怎么用」不再丢失，表格也能被正确读出结构
- **搜索改为多后端自动回退，并新增 Tavily**：`[search].backend` 默认 `auto`，按 `tavily → brave → bing → ddg` 依次尝试，某后端报错 / 被限流 / 被反爬 / 无结果就自动试下一个，全失败时汇总各后端原因；固定后端失败会提示可改用 `auto`。新增 Tavily（专为 LLM 设计，结果最干净、不受反爬影响，免费额度 1000 次/月），`smith setup` 可选采集 key
- **搜索被反爬拦截时不再误报「无搜索结果」**：识别到验证页时给出明确错误与下一步建议（稍后重试 / 改用 webfetch 抓已知网址）
- **网络工具支持系统代理**：搜索与抓取此前不读 `ALL_PROXY`、不支持 SOCKS，开了系统代理只有 LLM 能连；现在统一复用 LLM 客户端的代理语义（含 socks5）。同时修掉系统代理写 `socks://`（缺版本号）导致启动即崩的问题
- **抓取默认拒访内网地址**：webfetch 此前对任何地址照抓，模型可能被网页内容诱导去读本机服务或云凭据；现默认拒访**非公网地址**（回环、私网、链路本地含云元数据、CGNAT、保留段与多播），重定向逐跳校验。本地开发需要抓 localhost 时用 `allow_private_urls = true` 或 `SMITHCODE_ALLOW_PRIVATE_URLS=1` 放行
- **改用真实浏览器 UA**：此前 UA 自曝身份（`SmithCode/1.0`），部分站点（如 Stack Overflow）直接 403；403/429 现在说明原因并提示改用 websearch 找镜像 / 缓存

## 编辑与文件操作

- **编辑不再改写整个文件的换行符**：此前在 Linux 上编辑 CRLF 文件会把整个文件变成 LF（Windows 反之），只改一行却整个文件 diff 全红。现在读时归一化为 LF、写时按原文风格还原，只改动被编辑的行；UTF-8 BOM 不再被当作正文显示，非 UTF-8 文件给出中文友好错误而非裸异常
- **`run_command` 新增可选 `description` 参数**：推荐用 5-10 个字符说明运行目的（如「运行单元测试」），权限确认框会先展示该描述再跟截断后的命令摘要，长命令不再撑满弹窗

## 界面（TUI）

- **终端窗口标题随会话同步**：标题栏显示 `Smith · <会话标题>`，运行中加 `◐` 前缀，**等待你确认或回答时优先显示 `!` 前缀**——切走窗口再回来能一眼看出 agent 是卡在等信息。退出时用标题栈恢复你原来的窗口标题。`terminal_title = false` 或 `SMITHCODE_TERMINAL_TITLE=0` 可关闭
- **复制到系统剪贴板修复（VTE 系终端）**：GNOME Terminal / Tilix / xfce4-terminal 等此前「鼠标选中 + ctrl+c」静默失效，现在优先调用系统剪贴板命令，不可用时才退回原机制
- **大列表按住方向键不再闪烁**：`/model` 等选择面板 600 项实测每键终端写入由 2 次降到 1 次、字符量降到约 1/3
- **输入框高度随内容自适应**：多行输入不再被压进看不见的滚动区（`Shift+Enter` 换行本就可用，只是此前看不到）；空输入时有快捷键提示
- **提问面板统一走确认页**：单问题也先进入确认页核对再提交，与多问题一致；多选题一道未勾选时不再卡住，按 Enter 记为「（未选择）」继续
- 其余修复：正文折行不再固定 80 列（窗口缩放正确重排）、「已探索」块的折叠与状态显示、转轮行不再整行重绘（长耗时工具不闪）、底栏完整显示分支名、侧边栏计划区不再画滚动条

## 行为调整：迭代与目标推进默认不限

- `[limits].max_iterations`（单次任务最大迭代轮数）默认值由 `30` 改为 `-1`（不限制）：只要模型持续请求工具就继续循环，直到模型给出纯文本回复或你中断
- `[limits].goal_max_turns`（`/goal` 持久目标回合预算）默认值由 `50` 改为 `-1`（不限制）：目标持续自动推进，直到模型核验证据后声明完成 / 受阻，你暂停 / 清除 / 中断，或空转刹车触发
- 需要封顶时仍可显式配置正整数；`--max-iterations N` 与 `/goal budget <N>` 继续可用，`/goal budget` 新增 `unlimited` / `off` / `none` / `-1` 取消上限
- 进度展示随预算自适应：不限时只显示回合数（如 `◎ 目标 3`），有预算时显示 `N/M`
- 旧会话快照中保存的旧默认值（30 / 50）不受影响，按快照原值执行

## 达到迭代上限时改为「强制总结收尾」

此前达到 `max_iterations` 会静默硬中止；现在改为注入收尾提示、以 `tools=None`（不向模型暴露工具）强制模型用纯文本总结：已完成工作、剩余任务、下一步建议。总结正文在流式过程中展示，终端另可见一条「已达上限」警告。

## 手动压缩 `/compact` 不再卡界面

此前 `/compact` 在宿主主线程同步执行，摘要请求期间界面整个卡死。现在 `/compact` 改为**后台压缩**：发送后立即提示「正在压缩上下文…」，界面保持可响应，完成后提示「上下文压缩完成。」；压缩期间按 Esc / Ctrl+C 可中断，中断后提示「已取消压缩。」。历史太短、无中段可压时提示「没有可压缩的上下文」。

任务运行中 `/compact` 会被拒绝（与 `/new`、`/sessions` 同属会改写会话状态的命令），避免与进行中的轮次冲突。

## 移除：子代理（Subagents）

**注意**：本版移除了子代理子系统与 `task` 工具。若你写过 `~/.smithcode/agents/` 或项目 `.smithcode/agents/` 定义、或用过 `[subagents]` 配置段，升级后将被忽略（无需手动清理）。

## 修复：LLM 流中途断连自动重试

推理模型思考时，对端（服务商 / 网关 / 代理）可能因空闲超时掐断长连接（表现为 `RemoteProtocolError: incomplete chunked read`）。此前这类**流中途**的传输层错误不在重试范围内，会直接中断任务；现在 `RemoteProtocolError` / `ReadError` / `ReadTimeout` 均纳入瞬时错误重试：

- 每次重试前在终端打印错误详情，方便定位是哪一层断的
- 已输出过正文的流不重试（重放会重复打印）；仅输出过思考内容时可安全重算
- 重试次数用尽仍失败则照常报错

## 升级方式

```bash
# uv tool 安装（推荐）
uv tool install --reinstall -e .

# 或从产物安装
pip install smithcode-0.9.1-py3-none-any.whl
```

如需恢复旧的上限行为，在 `~/.smithcode/config.toml` 中显式设置：

```toml
[limits]
max_iterations = 30
goal_max_turns = 50
```
